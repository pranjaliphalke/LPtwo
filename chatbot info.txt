def guess_age():
    print('Let me guess your age.')
    print('Enter remainders of dividing your age by 3, 5, and 7.')
    rem3 = int(input())
    rem5 = int(input())
    rem7 = int(input())
    age = (rem3 * 70 + rem5 * 21 + rem7 * 15) % 105
    print(f"Your age is {age}; that's a good time to start programming!")
This uses the Chinese Remainder Theorem to guess the user’s age based on remainders when their age is divided by 3, 5, and 7.

4. count()

Copy

def count():
    print('Now I will prove to you that I can count to any number you want.')
    num = int(input())
    for i in range(num + 1):
        print(f"{i}!")
This function demonstrates a for loop.

The user inputs a number, and the bot counts from 0 up to that number, printing each with an exclamation mark.

def test():
    print("Let's test your programming knowledge.")
    print("Why do we use methods?")
    print("1. To repeat a statement multiple times.")
    print("2. To decompose a program into several small subroutines.")
    print("3. To determine the execution time of a program.")
    print("4. To interrupt the execution of a program.")
    answer = 2
    while True:
        guess = int(input())
        if guess == answer:
            print("Completed, have a nice day!")
            break
        else:
            print("Please, try again.")
A simple quiz with one correct answer (option 2).

A while True loop keeps asking until the correct answer is given.

This tests logical thinking and introduces the idea of validating user input.
