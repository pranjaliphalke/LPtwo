🔁 Linear Search Loop

Copy
Edit
        for(integer i = 0; i < lon.size(); i++)
        {
            if (key == lon[i])
            {
                s = 1;
            }
        }
Loops through each index of the list.

Compares each element to the key.

If a match is found, sets s = 1.

Note: It does not break out of the loop early. It continues checking all items even if the key is found.
