We import deque from collections — this is a double-ended queue. It allows us to efficiently pop from the front (O(1)) which is better than using a list (pop(0) is O(n)) for Breadth-First Search (BFS).

def dfs(visited, graph, node):
    if node not in visited:
        print(node, end=" ")
        visited.add(node)
        for neighbour in graph[node]:
            dfs(visited, graph, neighbour)
Explanation:
This is a recursive Depth-First Search (DFS).

visited is a set() to keep track of visited nodes.

If the current node is not visited:

Print it.

Mark it as visited.

Recursively call DFS on each of its neighbors.

The recursion will go as deep as possible before backtracking.

def bfs(visited, graph, start_node):
    queue = deque()
    visited.add(start_node)
    queue.append(start_node)

    while queue:
        node = queue.popleft()
        print(node, end=" ")
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.append(neighbour)
Explanation:
This is Breadth-First Search (BFS) using a queue.

Start by marking the start node as visited and enqueue it.

While there are nodes in the queue:

Dequeue the first one.

Print it.

Visit all unvisited neighbors, mark them visited, and enqueue them.

This explores level by level (breadth-first).
