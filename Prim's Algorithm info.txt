What is Prim's Algorithm?
Prim’s Algorithm is a greedy algorithm used to find the MST. The idea is:

Start from an arbitrary node.

Grow the MST by always choosing the smallest weight edge that connects a new vertex to the tree.

Repeat until all vertices are included.

🔍 Function: prim_mst(graph, start=0)
Input:
graph: A dictionary of lists (adjacency list), where graph[u] = [(v, weight), ...].

start: The starting node for MST (default = 0).

min_heap: A priority queue that stores the minimum-weight edge available at any point.

🧮 Time Complexity
Using a Min Heap: O(E log V)

Where:

E = number of edges

V = number of vertices

Efficient for sparse graphs due to heap optimizations.

🧠 Summary
Uses a Min Heap to always pick the next lowest-weight edge.

Maintains a visited set to avoid cycles.

Builds the MST incrementally starting from a chosen node.

Very suitable for dense or connected undirected graphs.
