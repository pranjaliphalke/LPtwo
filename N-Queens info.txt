 The N-Queens Problem
Goal: Place n queens on an n×n chessboard such that:

No two queens attack each other (no two in the same row, column, or diagonal)

def print_solution(board):
    n = len(board)
    for row in range(n):
        line = ""
        for col in range(n):
            if board[row] == col:
                line += "Q "
            else:
                line += ". "
        print(line)
    print("\n")
Takes a board array, where board[i] stores the column position of the queen in row i

Prints the board using:

Q for queen

. for empty cell

🧠 Part 1: Backtracking Algorithm
🔍 is_safe(board, row, col)

def is_safe(board, row, col):
    for i in range(row):
        if board[i] == col or \
           board[i] - i == col - row or \
           board[i] + i == col + row:
            return False
    return True
Checks if placing a queen at (row, col) is safe:

Same column check: board[i] == col

Same diagonal checks:

\ diagonal: board[i] - i == col - row

/ diagonal: board[i] + i == col + row

🔁 solve_bt(board, row, n)

def solve_bt(board, row, n):
    if row == n:
        print("Backtracking solution:")
        print_solution(board)
        return True
Recursively tries to place a queen in each row.

Tries all columns in that row.

If placing in column col is safe, recurse to next row.

If no valid move, backtrack by resetting board[row] = -1.

This is a basic brute-force recursive algorithm with pruning via is_safe().

def n_queens_backtracking(n):
    board = [-1] * n
    if not solve_bt(board, 0, n):
        print("No solution found using Backtracking.")
Initializes board with all -1 (no queens placed yet)

Starts solving from row 0

🧠 Part 2: Branch and Bound
Branch and Bound improves over backtracking by using auxiliary arrays to avoid recalculating diagonal and column constraints every time.

👇 solve_bb(n)

Copy

def solve_bb(n):
    cols = [False] * n                  # Track which columns are occupied
    diag1 = [False] * (2 * n - 1)       # "/" diagonals
    diag2 = [False] * (2 * n - 1)       # "\" diagonals
    board = [-1] * n
diag1[row + col]: For / diagonals

diag2[row - col + n - 1]: For \ diagonals

cols[col]: Keeps track of which columns are occupied

⚖️ Comparison Between Backtracking vs Branch & Bound
Aspect	Backtracking	Branch and Bound
Approach	Try all options, backtrack on failure	Use tracking arrays to prune earlier
Speed	Slower for larger n	Faster — avoids repeating checks
Efficiency	Moderate	Better due to reduced conflict checks
Memory Use	Low	Slightly more due to extra arrays
Logic Simplicity	Very simple	More logic, but more optimized
