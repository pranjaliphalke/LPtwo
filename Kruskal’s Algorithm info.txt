 What is Kruskal’s Algorithm?
Kruskal’s Algorithm is a greedy algorithm that builds the MST by:

Sorting all the edges by weight (ascending).

Picking the smallest edge that doesn’t form a cycle.

Repeating until V - 1 edges are added (where V is number of vertices).

To avoid cycles, we use a Disjoint Set (Union-Find) data structure.

📦 Class: DisjointSet
This class supports efficient union and find operations with optimizations.

class DisjointSet:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
parent[i] is the representative of the set containing element i.

Initially, every node is its own parent (its own set).

rank[i] helps to keep the tree flat by tracking the "depth".

def find(self, u):
    if self.parent[u] != u:
        self.parent[u] = self.find(self.parent[u])  # path compression
    return self.parent[u]
Finds the representative of the set containing u.

Path compression: makes future queries faster by flattening the tree.

def union(self, u, v):
    root_u = self.find(u)
    root_v = self.find(v)

    if root_u == root_v:
        return False  # already connected

    if self.rank[root_u] < self.rank[root_v]:
        self.parent[root_u] = root_v
    elif self.rank[root_u] > self.rank[root_v]:
        self.parent[root_v] = root_u
    else:
        self.parent[root_v] = root_u
        self.rank[root_u] += 1
    return True
Unites two sets if they are disjoint (no cycle will be formed).

Uses union by rank to attach the smaller tree under the root of the bigger one (more efficient).

🌳 Function: kruskal_mst(vertices, edges)

def kruskal_mst(vertices, edges):
    edges.sort(key=lambda x: x[2])  # sort by weight
    ds = DisjointSet(vertices)
    mst = []

    for u, v, w in edges:
        if ds.union(u, v):
            mst.append((u, v, w))

    return mst
Sorts all edges by weight using sort(key=lambda x: x[2]).

For each edge (u, v, w):

If u and v are not already connected, include it in the MST.

Stops when we have V-1 edges.

def main():
    edges = []

    n = int(input("Enter number of vertices: "))
    e = int(input("Enter number of edges: "))

    print("Enter edges in format: u v w (edge from u to v with weight w):")
    for _ in range(e):
        u, v, w = map(int, input().split())
        edges.append((u, v, w))

    mst = kruskal_mst(n, edges)
    total_weight = sum(w for _, _, w in mst)

    print("\nMinimum Spanning Tree (Kruskal's):")
    for u, v, w in mst:
        print(f"{u} - {v} : {w}")
    print(f"Total weight of MST: {total_weight}")
Takes user input for number of vertices n and edges e.

Accepts each edge in the format u v w.

Calls kruskal_mst to get the MST.

Prints the MST edges and total weight.

🧮 Time Complexity
Step	Time Complexity
Sorting edges	O(E log E)
Union-Find ops	O(α(N)) per op (very close to constant)
Total	O(E log E)

Where:

E = number of edges

N = number of vertices

α(N) = inverse Ackermann function (very slow-growing)

📌 Summary
Efficient use of Disjoint Sets avoids cycles.

Greedy selection of edges results in a minimal total weight.

Modular design — easy to adapt or extend.
