 What is Selection Sort?
Selection Sort is a simple sorting algorithm that divides the input list into two parts:

Sorted part at the front (left)

Unsorted part at the back (right)

The algorithm repeatedly selects the minimum element from the unsorted part and places it at the beginning (adds it to the sorted part).
That's why it's called greedy — it always takes the best (smallest) option available at each step.

📌 Step 3: Inner loop — find the minimum element in the rest

    for j in range(i+1, n):
        if arr[j] < arr[min_idx]:

You iterate through the unsorted portion of the array (i+1 to n-1).

min_idx gets updated if a smaller element is found.

📝 Greedy Choice: At each step, choose the smallest available element.

📌 Step 4: Swap the found minimum with element at i

After finding the smallest element in the unsorted part, swap it with the element at the current index i.

🧮 Time & Space Complexity
Complexity	Value
Time (Worst/Avg)	O(n²)
Space	O(1)
In-place?	Yes
Stable?	No (can be modified to be stable)

🔚 Summary
Greedy logic: Always pick the smallest available element.

Simple to understand and implement.

Efficient for small datasets, but inefficient for large ones due to O(n²) time.
