def heuristic(start, goal):
    global g
    h = 0
    for i in range(9):
        for j in range(9):
            if start[i] == goal[j] and start[i] != -1:
                h += (abs(j - i)) // 3 + (abs(j - i)) % 3
    return h + g
This tries to implement Manhattan Distance, a common heuristic for 8-puzzle:

For each tile, compute the distance between its current and goal positions in row and column.

Adds that to the current move count g.

⚠️ Flaws:
Inefficient: It does a nested loop (O(n²)).

Better Way: Precompute goal positions into a dictionary for fast lookup.
