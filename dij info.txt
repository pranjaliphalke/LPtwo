🔁 4. Dijkstra’s Algorithm

def dijkstra(self, start):
    shortest_distances = {node: float('inf') for node in self.graph}
    shortest_distances[start] = 0
    previous_nodes = {node: None for node in self.graph}
    priority_queue = [(0, start)]
shortest_distances: Initially sets all node distances to ∞ (infinity), except the start node which is 0.

previous_nodes: Tracks the previous node on the shortest path for each node.

priority_queue: Min-heap initialized with the start node and distance 0.

def _reconstruct_paths(self, previous_nodes, start):
    paths = {}
    for node in self.graph:
        path = []
        current = node
        while current is not None:
            path.append(current)
            current = previous_nodes[current]
        path.reverse()
        if path[0] == start:
            paths[node] = path
        else:
            paths[node] = None
    return paths
For every node, traces back using previous_nodes from the end node to the start.

Reverses the path to give it in start → end order.

If a path doesn't start with the source, it's considered unreachable.
